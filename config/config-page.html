Add every system you ride, for example one per city. Each one is only asked for buses when you're inside its coverage area. Automatic coverage is the area around the stops you've saved for that system. Some systems need a free API key; the key field says where to get one. A new system starts out covering its home city. OneBusAway works with any OneBusAway server (blank = Puget Sound with the public TEST key). Mock serves made-up data for trying the app.
